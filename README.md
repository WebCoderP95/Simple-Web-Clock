🌍 World Clock / Relógio Mundial

A simple web clock with:

- ⏰ Toggle between 12h and 24h formats
- 🌐 Language switch (Portuguese 🇧🇷 / English 🇺🇸)

🚀 Features

- Real-time clock updating every second
- Clean and minimal interface
- Dynamic text updates based on selected language

🛠️ Tech Used

- HTML
- CSS
- JavaScript (Vanilla)

🎮 How to Use

- Click the format button to switch between 12h and 24h
- Click the language button to switch between Portuguese and English

📌 Notes

This project was built as a learning exercise focused on DOM manipulation and basic state management.
